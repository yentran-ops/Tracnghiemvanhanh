Mật khẩu ở đâu?

Trang quản trị không có tài khoản riêng. Mật khẩu chính là giá trị của biến ADMIN_PASSWORD do bạn tự đặt trên Vercel:

  1. Vào vercel.com → chọn project tngquiz
  2. Mở Settings → Environment Variables
  3. Bấm Add: Key = ADMIN_PASSWORD, Value = mật khẩu bạn muốn (VD: TNG@admin2026) → Save
  4. Vào Deployments → ⋯ → Redeploy
  5. Quay lại trang này, nhập đúng mật khẩu vừa đặt

Quên mật khẩu: vào lại bước 2 để xem hoặc đổi giá trị, rồi Redeploy.
